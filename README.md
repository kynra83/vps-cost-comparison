## CN2 GIA-E 到底是什么线路，和 CN2、CN2 GIA 差在哪

CN2 GIA-E 是搬瓦工基于中国电信 CN2 网络（AS4809）做的电商级线路套餐，和另外两个系列的差别可以拆成三层理解：

- **CN2（GT）**：走 AS4809 的 GT 网络，价格便宜（入门款 1GB 配置年付只要 $49.99），但这条线路 2019 年之后拥堵明显，晚高峰体验和普通 163 骨干网差距不大。
- **CN2 GIA**：GIA 全称 Global Internet Access，是 CN2 网络里的高端商用路由。官方自己的说法是，这是「传输数据到/自中国最贵的方式」，但多年来问题最少、非常稳定，适合网络会议、VOIP 这类对延迟敏感的场景。
- **CN2 GIA-E**：在 GIA 基础上做的电商增强版。带宽从 1Gbps 起跳拉到 2.5Gbps，最高 10Gbps，并且三网回程都有专门优化：电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走 China Unicom Premium（AS10099）。不管你家里是哪家的宽带，回程都有对应的优化线路，这是它和普通 GIA 版本最大的实际区别。

还有一个隐性差别：CN2 GIA-E 套餐可以在十几个机房之间自由切换，而香港、东京那些单机房 GIA 套餐只能待在原机房。这一点后面单独讲，它其实是 GIA-E 性价比的重要组成部分。

优惠和价格说完了，这几条限制反而更影响长期使用体验，都来自官方条款和帮助文档，下单前值得过一遍：

**CPU 有使用率上限。** 官方 Knowledge Base 标注 DC6 Plan 和 DC9 Plan 的 CPU 限制为单核的 30%（按一小时平均使用率计算，偶发超限不影响）。编译、转码这类需要长期吃满 CPU 的任务，要掂量一下这个天花板；GIA-E 系列里 24 核的 1280G 顶配档就是给这类需求准备的。

**不抗 DDoS。** CN2 GIA 线路容量有限，遇到攻击时官方的处理方式是对 IP 执行 nullroute（黑洞路由）。打算在上面跑容易被打的业务，需要自己前置 Cloudflare 之类的防护，这一点没有商量余地。

**流量是月度额度，超出要花钱。** 流量每月重置，用超之后按 $1/GB 计费，或者在 KiwiVM 面板里升级套餐。拿 20G 档的 1TB 来说，跑大流量下载服务的话一个晚上就可能见底，选档时按真实用量往上留点余量。

**Self-managed，没有应用层运维。** 搬瓦工的服务是自助管理，面板功能（重装系统、快照、API、rDNS）很全，但环境部署和故障排查要自己动手。另外主域名 bandwagonhost.com 在大陆可能无法直接访问，官方提供了 bwh81.net、bwh88.net、bwh89.net 几个镜像域名，内容和主站完全一致。
